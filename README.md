# 07-revflow（冲流台）

冲流台 — 正向与冲正流水净额归并：正向装载 → 冲正关联入账 → 净额归并落余额 → 未平/超额隔离 → 流水净额与余额互证。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓分层建设，**不是** 交班过户。  
**也不是** 收银/退款 CRUD 后台、电商订单、报表 CSV 看板——主链是**流水管道与净额状态**，不是业务单据编辑台。

## 启动

```bash
# 后端
cd backend
pip install -r requirements.txt
set DATA_DIR=%CD%\data
set FIXTURES_DIR=%CD%\..\fixtures
uvicorn app.main:app --host 127.0.0.1 --port 10700

# 前端
cd frontend
npm install
npm run dev
```

## 主链

账户登记 → 装载正向流水 → 装载冲正并关联原单 → 跑净额归并（已配平落余额，未平/超额进隔离）→ 互证报告核对「流水净额 vs 账户余额」

装载重放换键时，在**键迁移台**登记 old_key→new_key（同账户），采用「独立迁移表 + 同事务整笔回滚」路径：

- **未终态冲正**（待归并/已隔离）：同一 SQLite 事务内 target 重指向新键、同步敞口键，已隔离项释放并复位待归并；
- **已终态冲正**（已归并）：历史配平事实不可改写，target 留在旧键，但在 `retarget_touches` 留下可查迁移边（终态留边），二次归并按家族映射仍能找到原单，不进假隔离；
- 家族（old+new 正向额度 − 有效冲正累计）合并后超额，或事务内任何一步异常，一律 `ROLLBACK` 回到迁移前——失败只留一行 `key_retargets` 闭失败登记，**禁止半截 target**；
- 迁移关系落三张独立表：`key_retargets`（迁移登记，old_key/new_key/敞口快照）、`retarget_touches`（逐冲正不可变迁移边，含触及冲正键、改前/改后 target、处置）、`retarget_repoint_proofs`（重指向证明实体：旧键、新键、重指向数、终态留边数、触及键全集、同账户未触及键）；
- 证明只读接口：`GET /api/key-retargets/{迁移id}/repoint-proof`（闭失败/不存在返回 404，证明随迁移事务同生共死）；正向/冲正流水界面同源展示迁移 id、证明 id 与处置字段。

是管道内键重映射，不是主数据 SCD。

## 界面约定

页面文案全部中文；入口：总览 / 账户 / 正向流水 / 冲正流水 / 归并台 / 未平隔离 / 净额互证 / 键迁移台。  
视觉：**左轨编号导航 + 右侧账册横线工作面**（Literata / JetBrains Mono，靛蓝强调）；**不是**交班台那种顶栏品牌+横向流程条。
